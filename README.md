# Gracias en Familia · Thankful Together

App (PWA) de **Vibras Positivas HM** para el Día de Acción de Gracias 2026, en español e inglés.

- **Hoy:** hora real de Colombia, cuenta regresiva a la cena, idea, pregunta y palabra en inglés que cambian cada vez que se entra.
- **Historia** (1621 → 2026) y **Costumbres**, con fotos reales de Wikimedia Commons y su crédito.
- **Menú a la colombiana:** pavo con naranja agria, relleno con chorizo antioqueño, puré de papa criolla, salsa de arándanos o mora, batatas con panela, pastel de ahuyama y gravy, con videos.
- **Muro de gratitud** (se guarda en el celular y se manda por WhatsApp), **Ronda en la mesa**, **Tarjeta** descargable, **Frases** para familia, amigos, equipo y clientes, y **vocabulario en inglés** con pronunciación.

Publicación: https://gracias-en-familia.netlify.app/

La imagen de vista previa (`og.jpg`) la genera el robot de GitHub Actions con una foto real (pestaña *Actions → Imagen de vista previa → Run workflow*).
